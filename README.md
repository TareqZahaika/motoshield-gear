# MotoShield Gear

Professional university project for a motorcycle safety gear e-commerce website.

## Pages

- `index.html` - home page
- `products.html` - product listing, search, and filters
- `product-details.html` - product details and customization
- `cart.html` - shopping cart
- `checkout.html` - customer, payment, and order form
- `about.html` - business concept and safety mission
- `contact.html` - contact form and Telegram section
- `admin.html` - demo admin dashboard

## Setup

1. Open `database/schema.sql` in Supabase SQL Editor and run it once.
2. Open `index.html` in a browser.

The Supabase project URL and publishable key are already configured in `js/supabase.js`.
Do not put Telegram bot tokens or service-role keys in frontend JavaScript.
